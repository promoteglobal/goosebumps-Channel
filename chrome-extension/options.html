Goosebumps Helper — GitHub Auto-Push

Paste your GitHub token once. Until you do, the extension behaves exactly as before (the terminal watcher handles uploads).

When a token is saved, after each MP3 finishes downloading the extension will:
1. Upload the MP3 to music/{genre}/
2. Upload blueprint.json to the same folder
3. Trigger the YouTube workflow
— all without your terminal. Clear the token anytime to fall back to the watcher.
